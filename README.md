# ردّاد — منصة وكيل مبيعات ذكي على واتساب

منصة كاملة إلك ولزبائنك: كل متجر بيفتح حساب، بيربط رقم واتساب تبعه، بيضيف منتجاته ومعلوماته، والوكيل الذكي بيرد على الزبائن، بيقترح المنتجات، وبيسجّل الطلبات.
بتشتغل على الكمبيوتر وعلى الموبايل (بتنزل كتطبيق PWA على الشاشة الرئيسية).

الكود كله إلك، بدون أي ترخيص بيقيّدك، وبدون n8n.

---

## شو فيها

**لكل متجر (مشترك):**
- ربط واتساب بطريقتين، وفيك تبدّل بينهن بأي وقت:
  - **ربط سريع مجاني**: بمسح QR أو بكود ربط بالرقم، إذا فاتح اللوحة من نفس الموبايل. بلا حدود رسائل، بس غير رسمي وفي خطر حظر.
  - **ربط رسمي (Cloud API)**: آمن ومستقر. أول 1000 رد خدمة بالشهر مجاناً من ميتا.
- **وكيل مبيعات ذكي**:
  - بيرد بلهجة الزبون، وبيقترح أنسب منتج مع السعر والصورة.
  - بيتعامل مع الاعتراضات، وبيجمع معلومات الطلب وبيسجّله.
  - بيحفظ ملاحظات عن كل زبون، متل مقاسه ولونه المفضل.
- **ما بيخترع**: بيجاوب بس من المنتجات والمعلومات يلي كتبتها. إذا ما عرف، بيحوّل لموظف.
- **تحويل لموظف**:
  - بكلمات مفتاحية متل "موظف"، أو لما الزبون يكون زعلان أو عنده طلب خارج صلاحية الوكيل.
  - لما ترد أنت من موبايلك أو من اللوحة، الوكيل بيسكت مع هالزبون لفترة.
- **توفير الرسائل**: الوكيل بيجمع رسائل الزبون المتتالية وبيرد برسالة وحدة، والصورة بتنبعت مع النص بنفس الرسالة.
- **صندوق محادثات مباشر** بيتحدّث لحظة بلحظة، مع زر "أنا برد / الوكيل يرد" لكل زبون.
- **الطلبات**: كل طلب بيسجّله الوكيل بيوصلك إشعار فيه على رقمك الشخصي، ومنه بتتابع حالته.
- **المنتجات**:
  - إضافة يدوية، أو رفع صور.
  - استيراد من ملف CSV أو Excel أو JSON، أو من رابط (متل `/products.json`).
- **إضافة بالصور والصوت**: بتصوّر المنتج، بتكبس المايك، وبتحكي الاسم والسعر والقياسات، والمنتج بيتسجّل لحاله. بيحتاج مفتاح Groq أو Gemini أو OpenAI لفهم الصوت.
- **ساحة تجربة**: بتحكي مع الوكيل كأنك زبون قبل ما يحكي مع زبائنك.
- **أوقات العمل**: الوكيل بيرد دائماً، أو بس برّا الدوام، أو بس بالدوام.
- **مفتاح الذكاء الاصطناعي**: كل متجر بيقدر يحط مفتاحه الخاص، فبتصير ردوده بلا حدود يومية:
  - مزوّدين مجانيين: Groq، Gemini، OpenRouter، Cerebras، Cloudflare.
  - مزوّدين مدفوعين: DeepSeek، OpenAI، أو أي مزوّد متوافق.

**إلك كمدير منصة** (أول حساب بيتسجل):
- قائمة المشتركين: تغيير الخطة، تمديد الاشتراك، إيقاف حساب.
- خطط الاشتراك: الأسعار، الحدود اليومية، المميزات. بتعدّلها كلها من اللوحة.
- طلبات الدفع: المشترك بيطلب ترقية وبيكتب رقم العملية، وأنت بتفعّل بكبسة. هيك بيشتغل الدفع اليدوي (شام كاش، حوالة…) هلق، وجاهز تضيف بوابة دفع لاحقاً.
- مفتاح الذكاء الاصطناعي للمنصة: أساسي واحتياطي، للمشتركين يلي ما حاطين مفتاحهم.
- اسم المنصة ولونها، وفتح وإغلاق التسجيل.

## التجربة على جهازك (5 دقائق)

1. نزّل **Node.js 22.13 أو أحدث** من [nodejs.org](https://nodejs.org).
2. افتح Terminal بمجلد `raddad` وشغّل:
   ```bash
   npm install
   npm start
   ```
3. افتح `http://localhost:3000`. أول حساب بتعمله بيصير **مدير المنصة**.
4. لتجرب بدون مفتاح ذكاء اصطناعي: شغّل `MOCK_AI=1 npm start`. هيك الردود بتكون تجريبية.

## التشغيل الحقيقي مجاناً: سيرفر Oracle + Cloudflare

السيرفر لازم يضل شغّال 24 ساعة، لأن ربط واتساب اتصال دائم. لهيك ما بيمشي على Cloudflare Pages متل المتجر.

### 1) سيرفر Oracle Cloud المجاني
1. افتح حساب على [cloud.oracle.com](https://cloud.oracle.com). بيطلب بطاقة للتحقق بس، وما بيسحب منها.
2. اعمل **Instance** بنظام **Ubuntu 22.04 أو 24.04**:
   - الأفضل **Ampere A1** بالشكل المجاني: لحد 4 معالجات و24GB رام بحسب العرض الحالي.
   - إذا قلك "Out of capacity"، جرّب بعد شوي أو اختار منطقة تانية.
   - البديل: **E2.1.Micro** (1GB). بيكفي لعدد قليل من الأرقام.
3. نزّل مفتاح SSH وادخل على السيرفر:
   ```bash
   ssh -i key.pem ubuntu@IP_السيرفر
   ```

### 2) تنصيب ردّاد
ارفع مجلد `raddad` للسيرفر (مثلاً بـ `scp -r -i key.pem raddad ubuntu@IP:~`)، وبعدين:
```bash
cd ~/raddad
sudo bash deploy/setup.sh
```
السكربت بينصّب Node، وبيشغّل المنصة كخدمة بترجع تشتغل لحالها إذا السيرفر عمل ريستارت.

عدّل الإعدادات:
```bash
sudo nano /opt/raddad/.env      # حط PUBLIC_URL وإيميلك
sudo systemctl restart raddad
```

### 3) رابط https مجاني بـ Cloudflare Tunnel
ما بتحتاج تفتح منافذ ولا شهادة SSL. ودومينك أصلاً على Cloudflare.
1. ادخل [one.dash.cloudflare.com](https://one.dash.cloudflare.com) ← **Networks ← Tunnels ← Create a tunnel** ← **Cloudflared**.
2. اختار **Debian/Ubuntu**، وانسخ أمر التنصيب يلي بيعطيك ياه (فيه توكن)، وشغّله على السيرفر.
3. بـ **Public Hostname**:
   - Subdomain: `app`
   - Domain: `ko-sport.online`
   - Service: `HTTP` ← `localhost:3000`
4. خلص. افتح `https://app.ko-sport.online`.

بعدها حط بـ `.env`:
```
PUBLIC_URL=https://app.ko-sport.online
```
وأعد التشغيل.

### أوامر مفيدة
```bash
sudo journalctl -u raddad -f        # السجلات المباشرة
sudo systemctl restart raddad        # إعادة تشغيل
sudo bash deploy/update.sh           # تحديث لنسخة جديدة (بياخد نسخة احتياطية أول)
```

**النسخ الاحتياطي:** كل البيانات بمجلد `/opt/raddad/data`: قاعدة البيانات، ربط واتساب، الصور، ومفتاح التشفير. انسخه كل فترة لمكان تاني.
⚠️ لا تحذف `data/.secret`. بدونه ما بتنفك المفاتيح المحفوظة.

## أول إعداد بعد التشغيل

1. **الذكاء الاصطناعي للمنصة**:
   - من **إدارة المنصة ← الإعدادات**، حط مفتاح Groq كأساسي. بتطلعه مجاناً من [console.groq.com/keys](https://console.groq.com/keys).
   - وإذا بدك، حط Gemini احتياطي.
2. **تعليمات الدفع**: من نفس الصفحة، اكتب كيف المشترك بيدفعلك.
3. **متجرك أنت (Ko Sport)**:
   - **المنتجات ← استيراد**: ارفع ملف المنتجات.
   - **شخصية الوكيل والمعرفة**: اكتب التوصيل، الدفع، والاسترجاع.
   - **جرّب الوكيل**.
   - **ربط واتساب**.
4. حط **رقمك الشخصي للإشعارات** بصفحة الوكيل، حتى يوصلك كل طلب.

## نصائح مهمة للربط السريع (QR)
- استخدم **رقم مخصص للمتجر**، مو رقمك الشخصي.
- الوكيل بيرد بس على يلي بيراسلوك. **لا تستخدم المنصة لرسائل جماعية**، هاد أسرع طريق للحظر.
- الرقم القديم يلي إله تاريخ استخدام طبيعي أأمن من رقم جديد.
- إذا متجر كبر أو صار بده ثبات، انقله للربط الرسمي من نفس الصفحة. محادثاته ومنتجاته بتضل متل ما هي.

## إذا الربط السريع ما اشتغل
مكتبة الربط السريع (Baileys) بتتحدث كل فترة لتلحق تحديثات واتساب. إذا ما طلع الكود أو انقطع الاتصال بشكل متكرر، حدّث المكتبة:
```bash
cd /opt/raddad && sudo -u raddad npm install baileys@latest && sudo systemctl restart raddad
```
وشوف السجلات بـ `sudo journalctl -u raddad -f`.

## الخصوصية
- مفاتيح الذكاء الاصطناعي وتوكنات ميتا بتنحفظ **مشفّرة**.
- انتبه: الحصص المجانية عند بعض المزوّدين (متل Gemini) ممكن تُستخدم لتحسين خدماتهم. للمتاجر الحساسة، استخدم مزوّد مدفوع أو حصة مدفوعة.

## بنية المشروع
```
server.js                 السيرفر و webhook ميتا
src/agent.js              عقل الوكيل: السياق، البرومبت، الطلبات، التحويل لموظف
src/ai.js                 مزوّدي الذكاء الاصطناعي (Gemini + أي مزوّد متوافق مع OpenAI)
src/products.js           المنتجات، البحث العربي الذكي، الاستيراد
src/whatsapp/baileys.js   الربط السريع (QR / كود ربط)
src/whatsapp/cloud.js     الربط الرسمي (Cloud API)
src/routes.js             كل الـ API
src/db.js                 قاعدة البيانات (SQLite مدمجة بـ Node، بدون تنصيب)
public/                   لوحة التحكم (PWA)
deploy/                   سكربتات التنصيب والتحديث
```

## للتطوير لاحقاً
- **بوابة دفع تلقائية**: الخطط والاشتراكات جاهزة بقاعدة البيانات. بتضيف الدفع بـ `routes.js` جنب `/api/billing/request`، وبعد الدفع بتحدّث `plan_id` و`plan_expires_at`.
- **موظفين لكل متجر**: جدول `users` فيه `role` (owner / agent) جاهز.
- **قنوات تانية** (إنستغرام، ماسنجر): بتضيف ملف بـ `src/whatsapp/` بنفس الشكل (`send` + استقبال يستدعي `handleInbound`).
